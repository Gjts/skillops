## Release blockers

The implemented P0 product surface is suitable for continued Limited Preview,
but general RC promotion is blocked by evidence that cannot be produced or
approved inside this working session:

1. The current working tree is not an immutable commit; no commit was requested.
2. The operator deferred a current-candidate macOS run for this Limited
   Preview; the predecessor result does not qualify for general RC promotion.
3. The required five-person first-use validation sample has not been run.
4. Independent manual reviewer and keyboard-only sign-off has not been recorded.
5. An RC owner must explicitly accept the documented transitive dependency risk
   or complete and revalidate a Promptfoo upgrade.

Re-run the full OS/Node matrix and this evidence protocol after creating an
immutable candidate. Do not relabel Limited Preview as RC until every blocker is
closed.
